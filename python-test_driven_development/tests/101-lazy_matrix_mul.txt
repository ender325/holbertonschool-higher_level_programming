======================================
How to use lazy_matrix_mul
======================================

Import the function:
    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Basic multiplication test:
    >>> lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]])
    array([[ 7, 10],
           [15, 22]])

Multiplication with floats and integers:
    >>> lazy_matrix_mul([[1.5, 2.0], [3.0, 4.0]], [[2.0, 1.0], [0.5, 2.0]])
    array([[ 4. ,  5.5],
           [ 8. , 11. ]])

Testing incompatible dimensions (NumPy raises ValueError):
    >>> lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2, 3], [4, 5, 6], [7, 8, 9]])
    Traceback (most recent call last):
    ...
    ValueError: matmul: Input operand 1 has a mismatch in its core dimension g[id], with size corresponding to input operand 0's core dimension g[id], but previous dimensions specify different sizes

Testing non-matrix arguments (e.g. strings or invalid types):
    >>> lazy_matrix_mul("not a list", [[1, 2], [3, 4]])
    Traceback (most recent call last):
    ...
    ValueError: Object arrays cannot be used for matrix multiplication
