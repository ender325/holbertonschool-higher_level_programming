===========================
How to Use lazy_matrix_mul
===========================

This module defines one function, lazy_matrix_mul(m_a, m_b), which
multiplies two matrices using NumPy's matmul.

Import the function:
    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Basic multiplication
====================
    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

Non-square matrices
===================
    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

    >>> print(lazy_matrix_mul([[1, 2], [3, 4], [5, 6]], [[1], [2]]))
    [[ 5]
     [11]
     [17]]

Floats
======
    >>> print(lazy_matrix_mul([[1.5, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7.5 11. ]
     [15.  22. ]]

Single element
==============
    >>> print(lazy_matrix_mul([[2]], [[3]]))
